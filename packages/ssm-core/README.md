# Native SSM core

This is a Python package boundary, not an inference implementation. Use Python 3.11 for the upcoming PyTorch/CUDA compatibility evaluation. Do not install against the system Python 3.15.

Phase 2 must establish licensed training data, tokenizer/G2P behavior, an architecture, checkpoint provenance, GPU compatibility, consent enforcement, and a streaming protocol. PyTorch and CUDA dependencies remain unselected until that evaluation. No synthetic audio or pretrained third-party API is substituted here.
